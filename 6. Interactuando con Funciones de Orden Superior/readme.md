# Córdoba Geek

Proyecto desarrollado como parte del curso de JavaScript.

En esta pre-entrega se trabaja con un array de objetos de tipo `Evento` y funciones de orden superior para interactuar con la información.

## Funcionalidades

- Mostrar todos los eventos.
- Buscar eventos por ID usando `find()`.
- Filtrar eventos por categoría usando `filter()`.
- Obtener un resumen de eventos y precios usando `map()`.
- Calcular la recaudación potencial usando `reduce()`.
- Reservar entradas y actualizar los cupos disponibles.

## Tecnologías utilizadas

- HTML
- CSS
- JavaScript

## Ejecución

Abrir `index.html` en el navegador y utilizar el menú mediante `prompt`.

Los resultados se muestran en la consola del navegador.
